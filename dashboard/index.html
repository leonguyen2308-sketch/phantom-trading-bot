Kill switch

Cancels every order, sells the position at market and stops trading. It fires on its own when:

  • drawdown from the equity high reaches 10%
  • 5 API errors happen in a row
  • the bot's position differs from the wallet balance
  • you send /kill on Telegram or run python -m phantom kill

On the real bot, reset happens on your Mac with python -m phantom reset, never from this page.
